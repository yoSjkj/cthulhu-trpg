# 룰 정답표

CoC 7판 기준. 이 문서가 코드보다 우선한다.
`[하우스룰]` 표시 항목은 의도된 단순화다. 7판과 다르다고 수정하지 않는다.

**이 문서는 사용자만 수정한다.**

## 능력치 생성

| 능력치 | 굴림 |
|---|---|
| STR, CON, DEX, APP, POW | 3d6 × 5 |
| SIZ, INT, EDU | (2d6+6) × 5 |
| LUCK | 3d6 × 5 |

한글 표기: STR 근력 / CON 체력 / SIZ 체격 / DEX 민첩 / APP 외모 /
INT 지능 / POW 의지 / EDU 교육

`[하우스룰]` 나이 보정 없음. 전체 재굴림 3회까지.

## 파생수치

- HP = floor((CON + SIZ) / 10)
- MP = floor(POW / 5)
- SAN 시작값 = POW  ※ ×5 하지 않는다. POW가 이미 ×5 되어 있다
- maxSAN = 99 − 크툴루신화 기술치
- MOV:
  - STR과 DEX가 둘 다 SIZ 미만 → 7
  - 하나가 SIZ 이상이거나 셋이 같음 → 8
  - STR과 DEX가 둘 다 SIZ 초과 → 9

## DB / BUILD

| STR+SIZ | DB | BUILD |
|---|---|---|
| 2 ~ 64 | -2 | -2 |
| 65 ~ 84 | -1 | -1 |
| 85 ~ 124 | 0 | 0 |
| 125 ~ 164 | 1d4 | 1 |
| 165 ~ 204 | 1d6 | 2 |
| 205 ~ 284 | 2d6 | 3 |

DB는 항상 문자열로 저장한다. (`'-2'`, `'0'`, `'1d4'`)

## 기술 포인트

- 직업 포인트 = EDU × 4 (직업 기술에만)
- 개인관심 포인트 = INT × 2 (전 기술)
- 1% 단위, 상한 90% `[하우스룰]`

## 판정

d100. 낮을수록 좋다.

| 등급 | 조건 |
|---|---|
| 대성공 | roll = 1, 또는 roll ≤ floor(기술치 / 5) |
| 어려운 성공 | roll ≤ floor(기술치 / 2) |
| 보통 성공 | roll ≤ 기술치 |
| 대실패 | 기술치 < 50 → roll ≥ 96 / 기술치 ≥ 50 → roll = 100 |
| 실패 | 그 외 |

**판정 순서 주의:** 대실패를 먼저 확인한다.
기술치 100 이상일 때 roll 100이 성공으로 처리되면 안 된다.

**대성공 조건 주의:** `floor(기술치 / 5)`에 기술치 하한을 걸지 않는다.
기술치 40이면 roll 8 이하가 대성공이다.

`[하우스룰]` 7판의 극단적 성공(Extreme)을 대성공으로 통합했다.

### 난이도

| 난이도 | 통과 조건 |
|---|---|
| normal | 보통 성공 이상 |
| hard | 어려운 성공 이상 |
| extreme | 대성공만 |

### 보너스 / 패널티 주사위

`[하우스룰]` d100을 두 번 굴려 낮은 값(보너스) 또는 높은 값(패널티)을 취한다.
7판의 십의 자리 재굴림 방식과 다르다. 개수는 1개만 지원한다.

### LUCK 소비

실패한 굴림을 성공으로 바꾼다.

- 비용 = 굴림값 − 해당 난이도의 목표치
  - normal → 기술치 / hard → floor(기술치/2) / extreme → floor(기술치/5)
- 소비한 만큼 LUCK 영구 감소
- 대실패에는 사용할 수 없다
- SAN 굴림, 피해 굴림에는 사용할 수 없다

### 밀어붙이기

실패한 판정을 1회 재시도. 대실패에는 사용할 수 없다.
재실패 시 단순 실패보다 가혹한 결과를 부여한다.
(HP 손실, SAN 체크, 전투 발생 중 하나 이상)

## SAN

- SAN 체크: d100 ≤ 현재 SAN이면 성공
- 손실량은 시나리오 JSON에 정의 (`{ success, fail }`)
- SAN 0 → 영구 광기 → 게임오버
- SAN은 maxSAN을 초과할 수 없다

### 광기

| 종류 | 조건 |
|---|---|
| 일시적 광기 | 한 번의 SAN 체크에서 5 이상 손실 → 1d10턴 지속 |
| 부정기 광기 | 세션 누적 손실 ≥ 세션 시작 SAN의 1/5 |
| 영구 광기 | SAN = 0 |

`[하우스룰]` 일시적 광기의 INT 판정 생략. 5 이상 손실 시 무조건 발동.

**부정기 광기 주의:** 기준은 **세션 시작 시점의 SAN**이다. 현재 SAN이 아니다.
현재 SAN을 쓰면 임계값이 계속 낮아져 매 턴 발동한다.

### 정신 상태 구간

SAN ÷ maxSAN 비율로 코드가 계산해 프롬프트에 전달한다.

| 비율 | 상태 |
|---|---|
| 70% 이상 | 안정 |
| 40 ~ 70% | 동요 |
| 15 ~ 40% | 왜곡 |
| 15% 미만 | 해리 |

## 전투

라운드 구조: DEX 높은 순서로 행동.

### 공격

무기 기술로 판정.

| 결과 | 피해 | 회피 |
|---|---|---|
| 대성공 | 최대 피해 + DB | 불가 |
| 어려운 성공 | 피해 굴림 + DB | 불가 |
| 보통 성공 | 피해 굴림 + DB | 가능 |
| 실패 / 대실패 | 없음 | — |

### 무기

| 무기 | 기술 | 피해 | 최대 | DB |
|---|---|---|---|---|
| 주먹 | 근접전투 | 1d3 | 3 | 적용 |
| 칼 | 근접전투 | 1d4+2 | 6 | 적용 |
| 권총 | 권총 | 1d10 | 10 | 미적용 |
| 소총 | 소총 | 2d6+4 | 16 | 미적용 |

### 피해 적용

- HP 0 이하 → 사망
- **중상**: 한 번의 공격 피해가 최대 HP의 절반 이상일 때
  ※ 현재 HP가 절반 아래로 내려간 것이 아니다
- 중상 시 CON 판정, 실패하면 기절
- 한 번의 피해가 최대 HP 이상이면 즉사

`[하우스룰]` 방어구·반격·관통 무기 미지원.
